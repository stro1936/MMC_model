# MMC_model
Semester project modelling a simple alpha beta controlled MMC done at UPC. Full details and results are in the PDF.
'PR_init_run' is the initialization file for 'ThreePhase_Energy' which contains the complete MMC model including energy control. Within the model there are parameters to change power setpoints and grid behavior.
'SOGI_bode' and 'PowerClarke' are references that calculate the bode characteristic of the SOGI controllers and the power equations in Clarke coefficients, respectively.
